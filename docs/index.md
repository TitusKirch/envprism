---
title: envprism documentation
description: Task guides for envprism, the TUI and CI check for keeping a set of .env files in step.
---

envprism shows every `.env*` file in a directory side by side and checks them
for drift. These pages cover what the README cannot: tasks that need more than
one command.

::page-cards
::

Installation, the keybindings and every configuration option are in the
[README](https://github.com/TitusKirch/envprism#readme); contributing is in
[`CONTRIBUTING.md`](https://github.com/TitusKirch/envprism/blob/main/CONTRIBUTING.md).
